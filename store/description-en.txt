Control your local Home Assistant instance from SailfishOS -- no cloud dependency, no Companion App required.

FEATURES

- Entity list (lights, switches, fans, covers) grouped by Home Assistant Area/Room, collapsible per room. Lights with a known color show a small color swatch next to the switch.
- Tap a light's name to open brightness, color and color-temperature controls -- only the controls that light actually supports are shown.
- Tap a thermostat's name to open a target-temperature slider and HVAC mode selection.
- Tap a media player's name to open play/pause/skip controls and a volume slider.
- Scenes show up as a one-tap "Activate" row.
- Sensor overview (temperature, humidity, pressure, battery, energy, power) grouped by room and collapsible, same as the room view.
- Updates overview: only devices with an actually pending update, with a one-tap install action and a live progress bar while installing.
- Live updates via WebSocket: changes made elsewhere (Home Assistant web UI, a physical switch, an automation) show up immediately, no manual refresh.
- Real push notifications: register as a genuine Home Assistant "mobile_app" device and receive notify.mobile_app_<device> pushes from your own automations, delivered instantly while the app is running -- no Google/Apple push service involved.
- Device status reported back to Home Assistant: battery level, charging state and connection type appear in Home Assistant as regular sensors for this device.
- Background notifications when a watched entity changes state, with a toggle button usable directly from the lock screen.

REQUIREMENTS

- A Home Assistant instance reachable on your local network.
- A Home Assistant Long-Lived Access Token (created under your Home Assistant profile -> Security).

This app talks directly to your own Home Assistant instance over your local network. It does not use or require any cloud service, and your credentials never leave your device except to reach the Home Assistant instance you configure.
